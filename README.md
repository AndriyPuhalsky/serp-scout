# serp-scout — MVP парсингу SEO-видачі для афіліат-команди

Щодня бере топ-10 Google (mobile, Канада) за 10 ключами казино-ніші, зберігає ключ / позицію / URL / домен / дату в SQLite, для кожного унікального URL через Claude визначає, чи це місце для розміщення брендів, які бренди згадано і як зв'язатися. Повторний прогін не дублює дані, а дописує історію позицій.

**Результат прогону 2026-11-04:** 10 ключів → 90 позицій → 77 унікальних URL, 54 релевантних для розміщення, 303 брендів, контакт у 36; файли `data/export/serp_2026-11-04.csv`, `labels.csv`, `history.csv`, база `data/serp.sqlite`. **Сайт-звіт для менеджера:** https://serp-scout.netlify.app (оновлюється після кожного щоденного прогону). **Методичка для маркетолога (замість відео):** https://serp-scout.netlify.app/guide/ — покроково, зі скріншотами. **Презентація для замовника:** https://serp-scout.netlify.app/presentation/.

## Як запустити

```bash
git clone https://github.com/AndriyPuhalsky/serp-scout && cd serp-scout
make install            # uv sync (потрібен uv: https://docs.astral.sh/uv/)
make demo               # офлайн: фікстури SerpApi + касети LLM, без ключів
cp .env.example .env    # вписати SERPAPI_KEY, ANTHROPIC_API_KEY (LLM_BUDGET_USD — ліміт $ на прогін)
make run                # живий прогін: SERP → сторінки → розмітка → SQLite
make export && make site && make serve   # CSV/JSON і сайт на http://127.0.0.1:8765
```

Щоденний запуск — GitHub Actions `daily.yml` (09:00 Київ): прогін, коміт даних, Netlify передеплоює сайт, зведення в Telegram. Повторний прогін у той самий день перезаписує снапшот дня; інший день — нова точка історії.

## Інструменти і чому

- **SerpApi** (Free, `device=mobile`, `gl=ca`) — легальний JSON-доступ до Google без скрейпінгу й капч; mobile і гео задаються параметрами.
- **httpx + trafilatura** — текст сторінки; при 403/капчі — Jina Reader; якщо й це не вдалось — розмітка за сніпетом з низькою впевненістю.
- **Claude Sonnet 5.5, structured output** — класифікація сторінки за схемою (тип сайту, релевантність, бренди, контакт, причина українською); кеш за хешем тексту, стоп при перевищенні бюджету.
- **SQLite** — нуль інфраструктури, дамп = файл у репозиторії; з нього ж CSV і сайт.
- **Статичний сайт на Netlify** — бонус «інтерфейс для менеджера» безкоштовно: фільтри, бренди, контакти, спарклайни позицій.

## Вартість одного прогону

З таблиці `runs` (деталі — `docs/10_ВАРТІСТЬ.md`): перший повний прогін 2026-11-04 — **77 URL, $1.35** (≈ $0.0175 на URL); перерозмітка на промпті v2 — ще $1.40; разом за день $2.74; щоденний прогін розмічає лише нові URL — оцінка $0.17–0.35 при 10–20 нових на день, $0 при незмінній видачі. SerpApi — 10 пошуків на день на тарифі Free (250/міс), $0. Actions, Netlify, Telegram — $0.

## Надійність і перевірка

Ретраї з бекофом на SerpApi/HTTP/Anthropic, таймаути, збій одного URL не валить прогін (`runs.status=partial` з переліком помилок), секрети лише в `.env`/GitHub Secrets і маскуються в логах. `make test` — pytest офлайн; `make lint` — ruff і узгодженість документів. Як це будувалось — `docs/` і `.claude/` (харнес Claude Code: агенти, скіли, хуки).
