disable-model-invocation: true

Додай запис у кінець `ЖУРНАЛ_ПОДІЙ.md`:

- Номер — наступний після останнього `### #NNN`. Дата — сьогодні за Києвом.
- Тип: рішення | зміна | дослідження | прогін | інцидент | деплой | інше.
- **Що / Чому / Наслідки / Файли** — факти; файли — з `git status --short` або `git diff --name-only`. Чого не знаєш — «—».
- Основа запису: `$ARGUMENTS` плюс контекст поточної розмови. Секрети не записувати (лише назви змінних).
