# 07 — Дизайн сайту-звіту

Напрям — редакційний звіт («папір і чорнило»): висока щільність даних, мінімум декору, типографіка спершу. Один `index.html` + `styles.css` + ES-модулі, без фреймворків і CDN.

## Токени (CSS custom properties)

| Токен | Світла | Темна |
|---|---|---|
| `--bg` | `#faf8f3` | `#14130f` |
| `--ink` | `#1b1a17` | `#ece8df` |
| `--muted` | `#6b6760` | `#9d988d` |
| `--line` | `#d9d4c8` | `#302d27` |
| `--accent` (релевантно) | `#1f6f4a` | `#5fbf8f` |
| `--warn` (needs_review) | `#9a6b00` | `#e0b64a` |
| `--neg` (нерелевантно) | `#8a3b2b` | `#d98570` |

Шрифти: заголовки — `Georgia, "Times New Roman", serif`; текст — системний sans; числа й URL — `ui-monospace, "SF Mono", Menlo, monospace` із `font-variant-numeric: tabular-nums`. Розміри: 14/16/20/28 px; інтерліньяж 1.45. Відступи: 4/8/12/16/24/40 px. Ширина контенту ≤ 1120 px; таблиця — горизонтальна прокрутка всередині картки на вузьких екранах, сторінка — без.

## Компоненти

- **KPI-плитка:** число (моно, 28 px, count-up) + підпис (muted, 14 px).
- **Таблиця розміщення:** домен (посилання, моно) · тип (чип) · релевантність (● accent/neg + %) · бренди (чипи, до 5 + «+N») · контакт (`mailto:`/посилання/—) · позиції по ключах (ключ: позиція, спарклайн історії inline SVG 60×16) · кнопка «чому» → `reason`.
- **Чип:** 12 px, рамка `--line`, без заливки; активний фільтр — заливка `--ink`, текст `--bg`.
- **Фільтри:** кластер, ключ, тип, бренд (select), пошук по домену/URL (input), сортування клік по заголовку.
- **Бари брендів:** горизонтальні, довжина = частка сторінок, підпис числом.
- **Спарклайн:** вісь Y інвертована (1 — вгорі), точки за датами, остання — акцент.

## Формат чисел і текстів

Числа — з `report.json`, без округлень «на око»; відсотки — 1 знак; вартість — `$0.00`; дата — `2026-11-04`. Порожнє — «—». Мова — українська.

## Рух і доступність

Reveal секцій на `IntersectionObserver`, count-up KPI 600 мс, усе вимкнено під `prefers-reduced-motion`. Контраст AA, видимий фокус, `aria-sort` на заголовках, `aria-label` на спарклайнах. Тема: `prefers-color-scheme` + перемикач (localStorage).
