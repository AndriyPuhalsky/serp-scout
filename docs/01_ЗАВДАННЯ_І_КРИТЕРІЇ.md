## Що просять

Афіліат-команда шукає в Google-видачі сайти, де можна розмістити казино-бренди. Потрібен прототип, що робить це автоматично:

1. Парсить топ-10 Google (mobile, Канада) за 10 ключами (список нижче).
2. Зберігає в БД або Google Sheets: ключ, позиція, URL, домен, дата.
3. Для кожного унікального URL через LLM визначає: релевантний для розміщення (оглядач/рейтинг — так; Вікіпедія або сайт казино — ні); які казино-бренди згадано; контакт для зв'язку, якщо є.
4. Готовий до щоденного запуску: повторний прогін не дублює дані й оновлює історію позицій.

**Здати:** посилання на репозиторій і результат прогону (таблиця або дамп); README на 1 сторінку (як запустити, які інструменти і чому, вартість одного прогону, що свідомо не зроблено і що далі); **коротке відео до 5 хв** з демонстрацією.

**Умови:** до 8 годин, 5 днів; будь-який стек і AI-інструменти; витрати на API до $50 компенсують.

**Бонус:** простий інтерфейс для менеджера **або** прохід партнерських редиректів (на який бренд веде посилання).

## Що оцінювач побачить (сценарій здачі)

1. Відкриває репозиторій: README на 1 сторінку, `data/export/*.csv`, посилання на сайт-звіт, посилання на відео.
2. Клонує, `make install`, `make demo` (без ключів) → підсумок прогону в терміналі; з ключами — `make run`.
3. Відкриває сайт: KPI, таблиця «куди йти з розміщенням», бренди, історія позицій, вартість.
4. Дивиться відео ≤ 5 хв.
