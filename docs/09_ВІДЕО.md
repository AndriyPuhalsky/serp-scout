# 09 — Сценарій відео (≤ 5 хв)

Оновлюється командою `/video` під актуальний стан. Цифри в репліках — лише з останнього прогону.

| # | Сцена | Хв | На екрані | Репліка (тези) |
|---|---|---|---|---|
| 1 | Задача і README | 0:40 | README у GitHub | Що просили; що здаємо: репозиторій, дамп, сайт, це відео. Як запустити за 3 команди. |
| 2 | `make demo` | 1:00 | термінал | Офлайн без ключів: 10 ключів × топ-10 → SQLite; підсумок прогону (SERP-виклики, URL, розмітка, $). |
| 3 | Сайт-звіт | 1:30 | Chrome | KPI; таблиця «куди йти»: фільтр «лише релевантні», бренди, контакт `mailto:`, позиції й спарклайн; «чому» — причина українською. |
| 4 | Надійність | 0:50 | термінал, Actions, Telegram | Повторний `make run` того ж дня — 0 дублів (`stats`); другий день — нова точка історії; Actions зелений; зведення в Telegram. |
| 5 | Компроміси | 0:40 | README | Вартість прогону з `runs`; що свідомо не зроблено; що далі. |

## Чеклист запису

- QuickTime ⌘⇧5, мікрофон увімкнено; термінал 140×40, шрифт 16; Chrome 1280×800, світла тема; зайві вкладки закриті, сповіщення вимкнені.
- Розігрів перед записом: `make demo`, `make serve`, відкрити сайт і Actions.
- Після запису: тривалість ≤ 5:00; викласти на YouTube (unlisted) або Google Drive; посилання — у README.
