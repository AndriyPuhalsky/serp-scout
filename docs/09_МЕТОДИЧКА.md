# 09 — Методичка для маркетолога і презентація для замовника (HTML, замість відео)

Рішення Р-024 (Андрій, 2026-11-04 12:44): замість відео ≤ 5 хв здаємо покрокову HTML-методичку, що «за руку» веде маркетолога через інструмент. Пишеться за скілом `developer-tutorial` (`.claude/skills/developer-tutorial/`, стороння, MIT): одна нова ідея на крок, очікуваний результат після кожної дії, контрольні точки, «якщо не так», настанови зменшуються до кінця — наприкінці учень робить сам.

## Параметри навчання

| Поле | Значення |
|---|---|

| Мета (що вміє після) | «Після методички ви самі за 10 хвилин дібрати зі свіжого звіту 5 сайтів для розміщення з контактом і причиною, пояснити колезі, чому саме вони, і перевірити, що звіт сьогоднішній» |
| Артефакт учня | таблиця «5 сайтів на сьогодні»: домен · тип · контакт · бренди-конкуренти · чому (шаблон у кроці 9) |
| Середовище | Chrome, https://serp-scout.netlify.app; крок 13 — термінал macOS (необов'язково) |
| Тривалість | 15–20 хв; крок 13 — ще 10 |
| Не охоплює | як влаштований код, налаштування Actions/Netlify (це `docs/06`), зміну ключів і промпту (`docs/03`) |

## Де живе і як публікується

- `site/guide/index.html` + `site/guide/guide.css` + `site/guide/img/*.png` → https://serp-scout.netlify.app/guide/ (Netlify публікує `site/` без збірки, Р-025).
- Посилання «Як користуватись» — у шапці звіту (`site/index.html`), у README (рядок «Методичка» замість «Відео») і в листі-здачі.
- Без JS-залежностей і CDN; стилі — токени `../styles.css` (`docs/07`, розділ «Методичка»), світла/темна тема, 360 px, `@media print` → зберігається в PDF з Chrome.
- Цифри — лише на скріншотах, з датою знімка в підписі; у тексті кроків їх не повторюємо, бо звіт оновлюється щодня (Р-025).

## Структура сторінки

Шапка: назва, для кого, що вмітимете, скільки часу, зміст (якір на кожен крок). Далі кроки. Кожен крок: заголовок-дія («Відкрийте звіт і перевірте дату»), 1–3 речення навіщо, одна дія, блок «Має бути так» (скріншот + очікуваний результат), за потреби «Якщо не так →» (якір на крок 12). ## Скріншоти

Знімаються headless Chrome без Playwright (Р-010, Р-025): `tools/guide_shots.mjs` (ops-engineer) читає `site/guide/shots.json` (report-frontend; записи `{out, url, selector?, click?, wait?}`) і через CDP (`--remote-debugging-port`, вбудований WebSocket Node ≥ 22, без npm-залежностей) робить `Page.captureScreenshot` з clip по селектору, за потреби клік перед знімком (відкрите «чому», увімкнений фільтр). 1280×900, світла тема, PNG ≤ 200 КБ, `make guide-shots`. Джерело — https://serp-scout.netlify.app (або локальний `tools/serve.py`). Зведення Telegram — текстом; скріншот з телефона Андрій додає за бажанням як `11-telegram.png`.
