Що ви замовили

Афіліат-команда шукає в Google сайти, де можна розмістити казино-бренди. Руками це довго і щодня застаріває. Потрібен прототип, який робить це сам.

  1. Щодня брати топ-10 Google — мобільна видача, Канада — за 10 ключами (5 груп: Грошові, Рейтинги, Платіжки, Бездеп/фріспіни, Грошові (провінція)).
  2. Зберігати ключ, позицію, адресу сторінки, домен і дату.
  3. Для кожної сторінки вирішити: чи можна тут розмістити бренд (оглядач чи рейтинг — так; Вікіпедія чи сайт самого казино — ні), які бренди вже згадано, кому писати.
  4. Повторний запуск не створює дублів, а дописує історію позицій.

Джерело: docs/01_ЗАВДАННЯ_І_КРИТЕРІЇ.md, розділ «Що просять».

Як це працює

Один прогін — шість кроків, без участі людини.

  1. SerpApiТоп-10 Google: мобільна видача, Канада. 10 запитів — по одному на ключ.
  2. SQLiteЗнімок дня: ключ, позиція, URL, домен, дата. Повтор того ж дня не дублює.
  3. Завантаження сторінкиСпершу напряму; якщо сайт закрився — через Jina Reader; якщо й так ні — сніпет із Google.
  4. Claude Sonnet 5.5Читає сторінку і заповнює чітку форму: тип сайту, чи можна розміститись, бренди, контакт, причина українською.
  5. CSV / JSONТаблиці для Excel і дані для сайту. Нові сторінки розмічаються, старі беруться з кешу.
  6. Звіт + TelegramСайт для менеджера оновлюється сам; короткий підсумок приходить у Telegram.

Сьогодні сторінки отримано так: напряму — 40, через Jina Reader — 27, лише за сніпетом — 10 із 77.

Звіт для менеджера

  • Шапка — дата прогону, статус, вартість: одразу видно, чи дані свіжі.
  • Підсумок — скільки сторінок, скільки підходять, брендів, контактів.
  • «Куди йти з розміщенням» — таблиця сайтів з фільтрами: група ключів, ключ, тип сайту, бренд, пошук по домену.
  • «Чому» — пояснення рішення українською і фрази-ознаки зі сторінки.
  • Контакт — email відкриває лист одним кліком, або посилання на сторінку для рекламодавців.
  • Позиції по ключах з маленьким графіком: вище — краще, остання точка — сьогодні.
  • «Бренди в топ-10» та історія позицій по днях.

Що буде, якщо щось зламається

Google або сайт відповів помилкою
Повторні спроби з паузою, що зростає; на кожен запит — таймаут.
Одна сторінка не відкрилась
Прогін не падає: сторінка розмічається за сніпетом з низькою впевненістю, а помилки потрапляють у статус «частково» з переліком. Сьогодні так розмічено 10 сторінок.
Запуск двічі
Дублів немає: знімок дня перезаписується, розмітка береться з кешу.
Модель витрачає забагато
Стоп за бюджетом: ліміт на прогін задає LLM_BUDGET_USD.
Ключі доступу
Лише в .env і GitHub Secrets (SERPAPI_KEY, ANTHROPIC_API_KEY, Telegram), у логах маскуються.
Чи це перевірено
Автотести працюють без інтернету і ключів; make demo проганяє весь шлях на записаних даних.

Наскільки можна вірити розмітці

18 / 20 збіг із незалежним суддею на 20 випадкових сторінках (перша версія промпту)

Обидві розбіжності мали одну причину: відповідь моделі обрізалась на довгих сторінках. На 18 нормально розібраних сторінках рішення «підходить / ні» і тип сайту збіглись повністю.

Що виправила версія 2

  • Більше місця на відповідь і автоматичний повтор, якщо відповідь не розібралась.
  • Перелічувати всі бренди з рейтингів, а не лише верх списку (на v1 повнота брендів була ≈ 50 %).
  • Сторінка для рекламодавців важливіша за загальний «Contact Us».
  • Рейтинги казино на медіа-сайтах — теж місце для розміщення.

Після перерозмітки всіх 77 сторінок на v2 — збоїв розбору 0.

Пакетна обробка Anthropic (Batches)
Дешевше, але відповідь приходить годинами; щоденний звіт потрібен зранку.
Акаунти, ролі, алерти на зміну позицій
Для прототипу на одну команду це зайве.
